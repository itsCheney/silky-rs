# 景の海のアペイリア

[English](apeiria.md) | 简体中文

日文版（SILKY'S PLUS WASABI，2017），带官方更新补丁。运行时根据目录中的 `apeiria.exe` 识别这个游戏；核对过的版本是 `apeiria.exe` 的 SHA-256 为 `dba4857ac6adb02b453a73694737124725bd4c91a9a7ecd60816fa7266e6317e` 的版本。程序版本 1.0.3.0，2017-11-09 链接，引擎配置为 [engine-2017](../builds/engine-2017.zh-CN.md)。

171 个脚本都能解码；剧情文本在脚本里（没有 MAP 表）。无头运行时，`silky-run snap` 能把整个剧情跑到结尾，所有引擎调用和 `Game` 调用都会执行。画面已与 Wine 下运行的原游戏对比过。

## 已完成

- 注音：`text 1` 开始一段注音，它的字符串标在随后的文字上方。运行时以一半字号画在那段文字上方。
- 选项使用引擎的 `Select.2`，返回所选的项，从 1 开始。
- 标题菜单，按可执行文件读出：`title.area` 中的六项，`title2.area` 中的附加页（CG、场景、音乐），`title_p.akb` 的格子，每格四行 42 像素的状态。没有存档时"继续"和"读取"为灰色；CG、场景和音乐需要字节变量 3002、3003 和 3004。
- 消息窗口：y = 508 处的一条渐变带（`message_p.akb` 的第 212..424 行，是可执行文件用窗口颜色填充的 alpha 遮罩），上面是淡淡的线条（第 0..212 行）。游戏自己的默认值：红 0、绿 25、蓝 46（满值 100），30 % 透明。
- 窗口按钮，按可执行文件读出：围绕 `MENU` 球的一圈按钮。球和圆环背景是 `menu_p00.akb` 的 302 像素格子；十一个按钮和隐藏按钮是 `message_p.akb` 的 40 像素格子。`mes_o.area` 中圆环按钮的 id 为 1..11（存档、读档、快速存档、快速读档、语音、上一个选项、回想、自动、跳过、下一个选项、设置）；隐藏按钮和窗口的坐标相对于窗口顶部。点击球可以收起圆环。
- 等待点击：`message_p.akb` 中的沙漏（从 (1280, 0) 往下十帧，每帧 76 x 80），位于 (1204, 642)，每十个 tick 换一帧，在 Wine 下测得 200 ms。
- 窗口位置：程序按 `/Config/MesWnd/Pos` 放置窗口各部分（沙漏在 Pos + 132），但只读取不写入；设置画面没有对应的选项，所以窗口一直在初始位置。
- 名字牌，按可执行文件读出：左端、按名字宽度重复的 14 像素中段、带花纹的右端，取自 `message_p.akb` 的第 584 行，每块下面是第 643 行同一块用窗口颜色填充的遮罩。名字位于牌内 69 像素、向下 17 像素处；牌的位置 (47, 498) 在 Wine 下测量。
- 文字：字形约 24 像素高，每 28.3 像素一个，从 x = 152 开始，行距 41，粗体加一像素黑边，在 Wine 下测量。
- 画面震动（`Game.993`），取自可执行文件：子命令 0 准备，2 从两张各八个偏移的表中选一张（只左右，或上下左右，最多 16 像素），3 开始，1 停止。画面每一步取下一个偏移；步长（六十分之一秒）是猜测值。
- 放大画面的白色闪光（`Game.1005`），取自可执行文件：画面放大到 120 %，变白，再用 16 帧淡回，步骤与 ふゆから、くるる。 相同。
- 随语音变化的图片（`Game.1007`，`.vo` 文件），取自可执行文件：语音开始后经过设定的时间，对话框头像（0）、立绘（1）、事件图及其差分（2）或全息面板上的アペイリア（3）换成文件指定的表情，标志置位时再加上脸红。若时间未到就进入下一句，变化会立即完成。`.vo` 格式比 ふゆから、くるる。 的旧：三个 u32 的头（数量、变化种类、毫秒），之后是 792 字节的记录（槽位、大小、标志、三个 260 字节的文件名）。原版会淡入新图片，这里是立即切换。
- 开启影片时（程序启动时的设置），脚本会在场景上播放角色换装的影片（`Game.999`，`chNN_chg.vsd`），并移动震动所用的画面副本（`Sprite.13`）；这些影片不会播放，场景保持与关闭影片时相同，但之后的 `Movie.3` 像原版一样返回 1。
