# 同級生 Remake

[English](doukyuusei.md) | 简体中文

Steam 版（Shiravune，2022），含英文、简体中文和繁体中文，没有日文文本。运行时根据目录里的 `doukyuusei.exe` 识别游戏；核对过的版本是 `doukyuusei.exe` 1.0.4.0，SHA-256 `9c9841fbca3a422a36f7ddef696f6164b4206ff622ecdb5cc1b4f45c8b231451`，2022-03-15 链接。引擎配置为 [engine-2022](../builds/engine-2022.zh-CN.md)。画面为 1920 x 1080。

这是一款在小镇里行动的冒险游戏：主角在暑假的每一天从一个地方去另一个地方，剧情由他查看的东西和遇到的人触发。这部分由脚本自己处理，再向引擎要各个画面（房间、城镇地图、时间段、在场的人）。
