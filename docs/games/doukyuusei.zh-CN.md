# 同級生 Remake

[English](doukyuusei.md) | 简体中文

Steam 版（Shiravune，2022），含英文、简体中文和繁体中文，没有日文文本。运行时根据目录里的 `doukyuusei.exe` 识别游戏；核对过的版本是 `doukyuusei.exe` 1.0.4.0，SHA-256 `9c9841fbca3a422a36f7ddef696f6164b4206ff622ecdb5cc1b4f45c8b231451`，2022-03-15 链接。引擎配置为 [engine-2022](../builds/engine-2022.zh-CN.md)。画面为 1920 x 1080。

这是一款在小镇里行动的冒险游戏：主角在暑假的每一天从一个地方去另一个地方，剧情由他查看的东西和遇到的人触发。这部分由脚本自己处理，再向引擎要各个画面（房间、城镇地图、时间段、在场的人）。

## 已完成

- 文本表：每个脚本 `X.MES` 有 `X_EN.MAP`、`X_CN.MAP` 和 `X_TW.MAP`。`Game.24(id, 0)` 取当前脚本文本表的第 `id` 行，供下一个 `MesWnd.3` 显示；`Game.24(id, 1)` 从 `NAMES_<lang>.MAP` 取说话人名字；`Game.24(name, 2)` 载入文本表。行里的 `\n` 换行，`\i` 切换斜体，`:myname:` 是主角的名字（Takurou、拓郎）。`Game.22` 让主角成为说话人。
- 消息窗口，在 Wine 下测量并对照可执行文件：
  - 窗口从 y = 730 开始（`/Config/MesWnd/PosY`）：先是 `message_p.akb` 第 0..350 行，不透明度 63 % 的黑色底（默认 `Alpha` 为 37），再是第 350..700 行的边框线。
  - 名牌：图集第 1350..1400 行（星形和金色横线）画在 (231, 799)，名字从 (294, 800) 开始。
  - 文字用游戏自带的位图字体，从 (242, 870) 开始：半角字母占 20 像素一格，全角字符占两格；行距 48 像素。与可执行文件一样，每个字形先在周围八个位置画成黑色，再画白色。`\i` 改用 `font_han_i.akb`。
  - 按可执行文件的方式按单词换行：一个单词（连同其后的空格）的字母会到达行首起第 74 格时移到下一行，末尾空格不计。已在 Wine 下对照许多英文行。
  - 按钮来自 `mes_o.area`：底部的跳过、全部跳过、自动、快速存档和快速读档（id 0..4，屏幕坐标），以及语音和关闭按钮（id 5、6，相对窗口顶部；画在点击区域左边一像素）。`message_p.akb` 的格子，按状态分行。
  - 点击等待：`message_p.akb` 的黄色标记（从 (1716, 700) 向下三帧，每帧 48 像素）画在 (1723, 996)。帧间隔是估计值。
  - 开头几行与 Wine 下的原版逐像素相差只有几个色阶。
- 标题菜单（`Game.28`）：`title_bg_<lang>.akb`（含标志）和 `title.area` 的六个项目，`title_p_<lang>.akb` 的 494 x 78 格子，每行三个，四个状态行；没有存档时“继续”和“快速读档”为灰色。附加页面（`title2.area`）：相册、回忆片段、音乐、一个隐藏的第四项和返回。新游戏返回 0，附加项目返回 257 到 260；退出直接关闭游戏。与 Wine 下的原版一致。
- 背景使用通用的 `Game.12` 调用。
- 无界面运行时，`silky-run snap` 能走到主角的房间：开场和第一通电话连同文字都能播放。
