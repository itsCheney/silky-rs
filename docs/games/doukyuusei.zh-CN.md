# 同級生 Remake

[English](doukyuusei.md) | 简体中文

Steam 版（Shiravune，2022），含英文、简体中文和繁体中文，没有日文文本。运行时根据目录里的 `doukyuusei.exe` 识别游戏；本页所述版本是 `doukyuusei.exe` 1.0.4.0，SHA-256 `9c9841fbca3a422a36f7ddef696f6164b4206ff622ecdb5cc1b4f45c8b231451`，2022-03-15 链接。引擎配置：[engine-2022](../builds/engine-2022.zh-CN.md)。画面为 1920 x 1080。

这是一款在小镇里行动的冒险游戏：主角在暑假的每一天从一个地方去另一个地方，剧情由他查看的东西和遇到的人触发。这部分由脚本自己处理，再向引擎要各个画面（房间、城镇地图、时间段、在场的人）。

无头运行时，`silky-run snap` 能播放片头，查看主角的房间，睡一小时，然后在城镇里一个地点接一个地点地走（走最短的路，不穿过其他地点），查看并交谈每个地点里的一切；跨越多天共走过两百多次拜访。

- 文本表：每个脚本 `X.MES` 有 `X_EN.MAP`、`X_CN.MAP`、`X_TW.MAP`。

### 步行地图（`Game.20`，`CCps`）

### 对话中的表情

- 引擎的 `Anime` 类运行 `.ax` 文件的帧程序：10 组每组 32 个程序，然后从字节 1280 起是七个数的单元格（类型、源 x、y、宽、高、屏幕 x、y），再是各个程序。操作有：画单元格、等待、保持（程序在被要求时停下或暂停的地方）、两层循环、重新开始、结束。每个运行中的程序每帧走一步。单元格来自精灵 5 中的图片（`Sprite.1(5, name)`）并画进背景，所以单元格会留到背景再次载入；类型 3 的单元格先把背景放回它自己下面。
- 对话先载入它的图片（一个人用 `c_ce.mes`，两个人用 `irce.mes`）：立绘，然后以三张图片叠上去的方式进入的脸，再是图集（`can.akb`，176 x 192 的脸，每个表情一列）和它的程序（`c.ax`，每个表情一个眨眼循环）。
- 背景之上的图片是 `Game.13` 的对象，按 id 区分（库只用 id 0，100 %）：子命令 0 `(frames, alpha, picture, id)` 放上一张与屏幕等大的图片（`c.akb`，立绘），子命令 1 `(frames, id, picture)` 把同样大小的图片叠到某个对象上（脸；没有对象则无效），子命令 4 `(frames)` 让所有对象淡出（库函数 39，在每段对话结束时），子命令 2 忘掉已淡出的对象。对象在时，`Anime` 单元格画在它上面而不是背景上。原版是淡化的同时程序继续运行；这里的淡化是整个屏幕的交叉淡化。
- `Game.34(index, group, name)` 把某个人（组）的脸换成某个表情（程序）；除非该程序已在运行，否则启动它。名字不使用。
- `Anime.10`（在下一个保持处暂停）和 `Anime.12`（等待程序结束）在这里不等待：前者立即暂停，后者立即把程序运行到结束。
