# なないろリンカネーション

[English](nanairo.md) | 简体中文

2014 年日文版。运行时根据游戏目录中的 `nanairo.exe` 识别这个游戏。程序版本 1.0.0.2，2014-09-09 链接。文件大小和 SHA-256 尚未记录。引擎配置：[engine-2017](../builds/engine-2017.zh-CN.md)。它自己的 `Game` 命令见 [game-commands.zh-CN.md](../game-commands.zh-CN.md#なないろリンカネーション)。

开发中。标题菜单、对话框和舞台上的图片已经绘制出来，还有几个画面和特效没有做。

在 Wine 下测量的只有对话文字的位置和行距，以及说话人名字的位置。下面其余的内容都读自可执行文件或脚本。页末的地址表给出具体位置。

## 已完成

### 标题菜单

- 五个条目（开始、继续、读档、设置、退出）在 (145, 255) 处一个 349 x 449 的图层上。(467, 517) 处的圆形附加按钮用来切换到鉴赏页再切回。鉴赏页有 CG、场景和音乐三项，在 (144, 313) 处一个 352 x 209 的图层上，另有返回按钮。
- 图格取自 `title.akb`，点击区域取自 `title.area` 和 `title2.area`。每个图格有普通、悬停、按下三行状态。
- 解锁靠字节变量。设置和附加按钮需要字节 3001，CG 需要 3002，场景 3003，音乐 3004。未解锁时是灰的。
- `Game.18` 的返回值：开始为 1，退出为 5，CG、场景、音乐分别为 257、258、259。继续、读档和设置打开引擎自己的画面。

### 对话框和按钮

- 对话框是 `meswaku.akb` 上方 199 行的透明度遮罩，用窗口颜色填充。它的顶端在 521（新安装时 `/Config/MesWnd/Pos` 的值）。
- 默认颜色为 19、70、133，默认透明度 50，都以 268 为满值。程序把每个值乘以 255 / 268。
- 按钮是 `meswaku.akb` 的图格，摆在 `mes.area` 的点击区域上，区域相对于对话框。编号 0 到 12：存档、读档、快速存档、快速读档、循环语音、隐藏、自动、快进、下一个选项、上一个选项、标题、回想、设置。图格有四行状态：普通、悬停、按下、禁用。自动、快进和循环语音开启时显示为按下。
- 点击等待：29 x 28 的标记，在 (1050, 对话框顶端 + 154)。目前只显示静止的一帧；图集中的各帧从 x = 691 起排成一行。

### 文字

- 字号 24，全角字符前进 28 像素，文字从 x = 258 开始，第一行基线在 y = 637，行距 32。这些是在 Wine 下测得的。字形带描边。
- 行长尚未测量，暂用 784 像素（28 格）。

### 说话人名字和头像窗口

- `Game.15(名字)` 设置说话人。名字为白色、22 号字，从 x = 258 起，基线在对话框顶端下方 80，直接画在对话框上，没有名牌。
- 头像窗口是角色图片上 532 x 544 的一块，缩小一半绘制在 (0, 448)。裁切的左上角随角色而定。表情图与身体图不同时画在身体图上。`12.5` 和 `12.6` 显示和隐藏，`12.7` 清空，`12.8` 显示整张图片。

### 立绘

- 图片为 1600 x 1600，名字是 `t` + 两个字母 + 数字。两个字母决定角色：iy 伊予，ai アイリス，ki 桔梗，fu 芙蓉，ko 琴莉，ao 葵，az 梓，yu 由美。
- 立绘的左边缘在 (1280 - 16 x 大小) / 2。左右位置再向外 345 像素。大小超过 50 % 时立绘上移 (2 x 大小 - 100) x K / 100，K 随角色而定（iy 400，ai 280，ko 和 ao 200，ki、fu、az 和 yu 140，其余 0）。
- `13.0` 放置立绘，`13.1` 移除一个，`13.7` 全部移除，`13.5` 设置表情层，`13.9` 缩放（这里立即生效），`13.2` 把所有变化按给出的最长时间交叉淡入。
- 背景和图片在精灵 2 中，位于立绘之下。精灵 3 是从不显示的图集存放处。

### CG 登记

- 脚本给出图片名（`14.10`）和按槽位顺序的各图层（`14.1`）。名字只有以 `H` 开头才会保留。场景提交时，在 493 行的表中查找这个组合。匹配时置位字节 3200 + 行号，同时置位字节 3001 和 3002。CG 鉴赏读取这些字节。
- 比较时忽略大小写和 `.akb`。

### 其他已执行的命令

`Game.19` 填充字节旗标，`Game.26` 在下一个脚本前结束对话框，`Game.27` 和 `Game.10` 做初始化，`Game.22.0` 登记当前显示的图片。见 [game-commands.zh-CN.md](../game-commands.zh-CN.md#なないろリンカネーション)。
