# 游戏

[English](games.md) | 简体中文

各个游戏在 silky-rs 上的运行情况。所有游戏共用的引擎功能见 [features.zh-CN.md](features.zh-CN.md)。`silky-run snap` 会列出运行时尚未执行的所有引擎调用。

## ふゆから、くるる。

国际版 1.0.1.0，日文、英文和简体中文。

全部 56 个脚本（约 790 万条指令）都能解码，所有跳转都落在指令边界上；全部 3,255 张图片都能解码。在无界面模式下，虚拟机能从 `start.mes` 启动，依次走过 logo、注意事项和标题脚本，并从 `fk001.mes` 开始执行剧情，三种语言的文本都能取到。所有路线都能玩到结局。

已与原版截图（Windows，简体中文）对照：对话框、名牌、对话框头像、中文文本的位置和字距，以及立绘的大小和位置。仍为暂定：英文文本的字体度量（还没有英文截图可对照）、两行文本的行距、换行宽度，以及选项在画面上的位置。

已从可执行文件读出并实现的特效：规则遮罩转场和画面变暗（精灵动画）、下雪、未来闪光、脉动缩放、斩击、白色缩放闪光、画面震动、角色摇摆，以及语音播放时变化的图片（`.vo` 文件）。近似处理：未来闪光时画面不会缩小，排队的音乐开始时没有淡入，角色跳动的步长时间是猜测值。

`Flag` 调用会把第 1000 号起的字节标志保存在系统数据中，跨周目保留，与可执行文件对其系统标志文件的处理一致。走完所有路线后，不再有未执行的引擎调用。“固定文字框”设置会被保存，但不起作用，因为这里的对话框本来就不会移动。

## きまぐれテンプテーション2

2024 年日文版，打了 1.02 补丁。

全部 64 个脚本和 712 张图片都能解码。在无界面模式下，`silky-run trace` 能启动到标题菜单并执行剧情，带说话人名字，支持日文。每个游戏都会给引擎加上自己的命令（原生类 29）；本作中哪些命令有返回值，是从它的可执行文件中读出来的。

### 界面

播放器和 `silky-run snap` 可以打开它。标题菜单、带说话人名牌的对话框、对话框按钮、侧边菜单、选项、行动菜单以及地图（包括第二张地图的子面板），都用游戏自带的图集绘制。对话框、行动菜单和地图的布局取自可执行文件，文字位置（包括两行文字）按游戏截图对齐。回想、存档读档、设置和确认对话框都已是游戏自己的样式，帮助文字取自游戏的 `.HLG` 表，声音页使用本作的九个角色语音分组。在行动菜单或地图处存档时，存的是它之前的那句对话。按钮栏的循环语音按钮会在语音结束时再次播放本句语音，全部快进按钮连未读文字也会跳过。跳转按钮快进到下一处未读文字或选项。按钮栏和侧边菜单的按钮会用游戏自己的气泡显示提示文字（`MesButtonHelp.hlg`），位置与可执行文件一致。自动模式会等语音结束，每句停留的时间按可执行文件计算；在对话上向下滚动滚轮与单击一样继续。

### 换装、笔记和收集品

这些画面用各自的图集绘制，并按可执行文件的方式读取脚本的字节变量：

- 字节 `900 + i` 非零时笔记第 `i` 条解锁，字节 `801 + i` 非零时收集品第 `i` 件解锁。
- 服装是字节 701（形态）和 708（服装切换），关闭画面时写回。字节 711 和 712 解锁形态 C 和 D。
- 从标题菜单打开笔记时读取脚本写在 `1000 +` 处的副本。从 1000 号起的字节变量保存在游戏之外的 `system.json` 中，读档和重新开始都不会丢失。
- 部分笔记条目会随剧情增长：字节 `940 + i` 表示已解锁几段，其余文字被截掉，最新一段前面有“New”标记（截断和标记位置取自可执行文件）。从标题菜单打开过该条目后标记消失（字节 2020 + i）。
- 最后一件收集品是一段语音记录，图片上是播放/暂停按钮，依次播放五个语音文件。可执行文件中的文件名是 `kt_*.ogg`，测试用的这份游戏里没有这些文件，因此会报告为缺失。

### 标题菜单和附加内容

标题按钮依次落下并弹跳到位，时间取自可执行文件。从游戏菜单回到标题时直接回到菜单，不再播放开头的标志。附加内容页上，音乐模式需要字节 3004，笔记需要字节 3006，Anne Viewer 和 Anne's Room 需要字节 3007（由结局设置），在此之前它们显示为灰色。缺失的音效文件只报告一次并跳过，和游戏一样。

CG、场景和音乐模式（`Game.30` 到 `Game.32`）是引擎自带的画面，布局和表格取自可执行文件。三者都用 `mode_p.akb` 绘制，已看过的内容记在 1000 号以后的字节变量中，由 `system.json` 跨周目保存：

- CG 模式：29 个条目共 268 张图，每页 12 个条目，每个条目显示已看/总数，并显示完成百分比。字节 `3300 + i / 8` 的第 `i % 8` 位表示第 `i` 张图已看过。画面上的图片及其图层与引擎表中的某一行一致时，引擎会设置这一位，运行时也照此处理。点击条目会打开它的图片网格，点击一张显示该图，再点击显示下一张已看过的图。
- 场景模式：六个场景，字节 3101 到 3106 非零时为已看过。点击后通过 `scmode.mes` 播放该场景。
- 音乐模式：29 首曲子（`kima2_01.wav` 到 `kima2_29.wav`），字节 3051 到 3079 非零时为已听过（由脚本设置），一次显示七行并带滚动条，另有音乐音量条。
- 各模式的解锁按钮会先询问，然后像游戏一样设置该模式的全部字节。

### E-mote

安娜莉丝是 E-mote 4 模型（`.psb`，文件头加密）：每套服装两个文件，`ta`/`tb` 加形态和服装编号（正是换装画面所选的那些），`_h0007` 含表情 0 到 7，`_h0813` 含表情 8 到 13。[Eluna](https://github.com/xmoezzz/eluna)（放在 `vendor/eluna_rs`，MPL-2.0，与 siglus_rs 所用的是同一份）负责解密并运行时间轴和物理。它输出的精灵（带纹理的三角形、六种混合模式、模板遮罩；DXT5 纹理）在播放器中由 wgpu 按窗口尺寸直接绘制到画面中，无界面模式下由一个小型软件光栅器绘制，两者结果相同。本作的密钥已内置；其他游戏由运行时搜索一次全部 2^32 个密钥（几秒到一分钟）。

有两个命令显示她，含义都读自可执行文件：

- `Game.10` 是和主人公一起行动时左下角的安娜莉丝：子命令 6 载入一套服装，7 设置表情和表情之后的那条时间轴，13（和 12）设置姿势，16 设置 `a` 时间轴，9 和 11 显示和隐藏。大小 0.35，位置参数为 (500, -930)。
- `Game.40` 按位置槽放置立绘模型：子命令 0（和 12）把一套服装载入某个槽，大小是脚本给出的百分比（居中时 50 和 100，右侧 60），1 设置表情，15 设置姿势，14 设置 `a` 时间轴，8 移动模型，3 移除一个槽，4 全部移除，2 按前面这些调用给出的帧数交叉淡化到新画面，与 `Game.13` 处理立绘的方式相同。子命令 16 给出刚开始播放的语音的口型数据（`k2*.csv`：UTF-16 文本的数字，每秒 60 个，即模型 `face_talk` 变量的值，范围 0 到 5）；语音播放期间，画面上所有安娜莉丝的嘴都按它开合。槽决定横向位置（0 居中，1 左，2 右），大小决定纵向位置，使脚的位置保持在同一条线上。

这些位置参数与画面坐标的对应关系，是用两张游戏截图（两种布局各一张）测出的，两者一致。GPU 绘制时动画每秒 60 帧（软件绘制时 15 帧）。在设置中关闭 E-mote 动画后画面保持静止。不带默认的 `emote` 特性编译时，这些画面会被省略。

`Game.10` 子命令 4 在每段 H 场景开头调用，是原版的场景跳过点：原版设置中“跳过 H 场景”打开时，场景在此结束。本程序不提供这个设置，所以该调用什么也不做，与原版关闭该设置时相同。

### H 模式

`Game.49` 是引擎自己的互动画面，含义读自可执行文件。脚本先把一对 `hg030100_*` 模型载入槽 0。玩家在右侧一栏选择动作，再点击触摸区域图 `anne_h.carea` 中的区域。每种动作和区域的组合播放可执行文件指定的时间轴、表情和语音。玩家操作时两个量表上升；量表满时播放收尾动画并等待其语音结束。各按钮用于切换服装、另一套模型和背景、自动重复，以及锁定量表。结束按钮选择收尾台词，然后回到脚本。

这些模型的单次时间轴标注的长度是 3 tick，而关键帧一直到 50 或 55；游戏会等它们播完，所以按最后一帧播放。
