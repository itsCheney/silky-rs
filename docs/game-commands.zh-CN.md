# Game 命令

[English](game-commands.md) | 简体中文

silky-rs 执行的原生类 29（`Game`）命令。调用写作 `Game.命令.子命令(参数)`；命令没有子命令时省略。“返回”是调用留在脚本栈上的值。最后一列是行为的可靠程度（见 [engine.zh-CN.md](engine.zh-CN.md#可靠程度)）。

## 先輩が私の妄想にドージンする

`games/doujin/`。读自可执行文件；这里的命令都尚未执行。有返回值的命令是 20、30、31、32、110、990 和 1009（总是返回），以及 40 的子命令 0 和 1、1006 的子命令 0（仅这几个）。后三者在被执行之前，模块给出 0。其他调用不会在栈上留下东西。

| 调用 | 返回 | 作用 | 来源 |
| --- | --- | --- | --- |
| `20(a, b)` | 一个数 | 选择：把两个值交给游戏的画面对象 | 读出 |
| `30`、`31`、`32` | 一个代码，或 -1 | CG、场景和音乐模式画面；画面失败或被离开时为 -1 | 读出 |
| `110(state)` | 选中的项 | 标题菜单 | 读出 |
| `990(value)` | 一个数 | 制作人员名单 | 读出 |
| `1009` | 0 或 1 | 第一个消息窗口条目的标志第 14 位已设置时为 1 | 读出 |
| `40.0(a, b)`、`40.1(a, b)` | 一个数 | 向同人志画面对象取结果（翻页或选择，具体不明） | 读出 |
| `1006.0(file, a, b, c, d, e)` | 一个句柄 | 按 `.brt` 文件在动画层列表中创建一项 | 读出 |

20、30 到 32、110 和 990 返回的代码含义尚不清楚。
