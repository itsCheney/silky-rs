# 引擎

[English](engine.md) | 简体中文

silky-rs 如何划分所有 Silky Engine 游戏共用的引擎和各个游戏自己加入的部分。共用引擎的功能见 [features.zh-CN.md](features.zh-CN.md)。

## 引擎和游戏

脚本用 `native` 调用引擎：先压入参数、子命令和类编号。类 1 到 28 属于引擎，每个游戏都带有。类 29（`Game`）是为每个游戏单独编写的：即使编号相同，各游戏的命令也不一样。

所以代码分成两部分：

- 引擎类在 `crates/silky-runtime/src/host.rs` 及其使用的模块中（精灵、画面、声音、存档、引擎画面）。它们按可执行文件中看到的引擎实现，这样尚未测试的游戏也能使用。
- 每个游戏自己的部分在 `crates/silky-runtime/src/games/<游戏>/` 中：它的 `Game` 命令、数据表和它自己的画面。`games/mod.rs` 中是足够通用、可以在任何游戏上尝试的 `Game` 命令（通用命令）。

`Game` 调用先交给正在运行的游戏的模块，再交给通用命令。谁都不处理的调用会连同参数一起报告并计数，绝不当作成功。[game-commands.zh-CN.md](game-commands.zh-CN.md) 列出了已处理的每个 `Game` 命令，包括它接收什么、返回什么，以及可靠程度。

## 引擎版本

每个游戏都链接着一份自己的引擎，引擎类在这些版本之间有变化。运行时根据程序的链接时间戳和文件大小识别版本，在版本不同的地方按它的配置处理；[builds/](builds/README.zh-CN.md) 列出了核对过的版本和每个配置的页面。

## 引擎类

| 类 | 名称 | 运行时的处理 |
| --- | --- | --- |
| 1 | Select | 选项设置；选项本身是一个 `Game` 命令 |
| 2 | MesWnd | 隐藏和显示对话框；日文版中显示文本 |
| 3 | Shake | 画面震动 |
| 10 | Font | 不使用：运行时自己排版文字 |
| 11 | Value | 尚未实现 |
| 12 | Mouse | 玩家是否点击，每帧查询一次 |
| 13 | Anime | 用 `.ax` 文件中的逐帧程序把图片表中的格子画进背景（眨眼的人物脸）；取自同級生 Remake 的程序，目前只用于该游戏 |
| 14 | Flag | 第 1000 号起的标志，跨周目保留 |
| 15、16、18 | Music、Effect、Voice | 声道、播放、停止、淡出、是否正在播放 |
| 17 | HEffect | 2017 版本中播放音效；其他版本尚未实现 |
| 19 | Sprite | 精灵层及其动画（规则遮罩转场、变暗） |
| 20 | Screen | 淡入淡出和规则遮罩转场 |
| 21 | Script | 跳转、调用和载入脚本 |
| 22 | BackLog | 日文版中传入文本；运行时自己维护回想 |
| 23 | Movie | `.vsd` 视频 |
| 24 | OneMes | 尚未实现 |
| 25 | Xml | 原版从 XML 文件读取的设置 |
| 26 | Ui | 等待和每帧查询 |
| 27 | Save | 脚本读档后据以重建场景的变量表：`2 (表, 键, 默认值)` 读取，`4 (表, 键, 值, 0)` 写入，`5 (表, 键)` 与 `6 (键)` 删除（分别从一张表、所有表中）。在ふゆから、くるる。与景の海のアペイリア中实现，存于场景内，因此存档带有它；运行时同时自己保存场景 |

## 可靠程度

文档和注释会说明每种行为的来源：

- **已对照**：与原版的截图或运行结果对照过。
- **读出**：从可执行文件中读出。代码中不写地址；各游戏页面列出了所核对版本中的地址。
- **脚本**：根据游戏脚本如何使用这个调用得出。
- **推测**：尚无依据确认的值，在代码中有标注。

## 本运行时自己的选择

以下内容不是原版的做法，与从原版读出的部分分开：

- 存档和设置是 JSON 文件（`system.json` 和每个存档一个文件，各带一张 PNG 缩略图），不是原版的格式。
- 字体由播放器指定；运行时不使用游戏自己的字体设置。
- 画面按游戏的尺寸（1280 x 720）合成，再一次缩放到输出尺寸；文字按输出尺寸绘制。
- 以帧为单位的时间按 1/60 秒计算。
- 原版提供而本运行时没有提供的设置（例如跳过 H 场景），按原版关闭该设置时的行为处理。
