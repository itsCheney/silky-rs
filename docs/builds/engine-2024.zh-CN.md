# engine-2024

[English](engine-2024.md) | 简体中文

`kimaten2.exe` 1.0.0.0（きまぐれテンプテーション2）中的引擎，2024-10-15 用 Visual Studio 2019 链接，SHA-256 `5cbd99107b94befe4935bbb7b8fdd7015d715a795945b434788657dee0a50d29`。程序里还留着ふゆから、くるる。的版本字符串；该游戏的下载版（[engine-2026](engine-2026.zh-CN.md)）与它的影片调用相同。

## 与 engine-2026 的不同

| 调用 | 本版本 | engine-2026 |
| --- | --- | --- |
| `Sprite.1` | 载入标题画面的按钮图集，由标题画面按格子绘制 | 显示图片 |
| 其他 `Sprite` 调用、`Flag`、`Mouse.4` | 尚未在这个版本上核对：不套用 2026 版本的处理，这些调用会报告为未执行 | 按该版本读出的行为处理 |
