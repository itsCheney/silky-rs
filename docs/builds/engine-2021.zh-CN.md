# engine-2021

[English](engine-2021.md) | 简体中文

ふゆから、くるる。盒装版（仅日文）中的引擎，Visual Studio 2019：

- 安装后的 `fuyukuru.exe` 1.0.0.0，2021-09-06 链接，SHA-256 `9797a7cb71955c0ddb4b4865e0e592166f82386a5e642bd25072922cf9d6d9fa`。
- 官方更新 1.01 的 `fuyukuru.exe` 1.0.1.0，2021-09-29 链接，SHA-256 `b5b163ceb979d9825c6586401da005d51a57f4005a93cf227ca304bf9e831988`。

用更新 1.01 核对：无头运行时剧情能跑通，所有引擎调用都会执行；标题菜单、设置、鉴赏页面和存档画面都能显示。除特别标注外，均来自脚本。

## 与 engine-2026 的不同

| 调用 | 本版本 | engine-2026 |
| --- | --- | --- |
| `Movie.0` | (文件) 设置影片 | (通道, 文件) |
| `Movie.3` | 播放影片，返回是否播放 | 不调用 |
| `Movie.2` | 关闭影片，不返回值 | 播放影片，返回是否播放 |

影片调用与 [engine-2017](engine-2017.zh-CN.md) 相同。

## 游戏数据

盒装版的日文图片使用不带语言后缀的文件名（`title_p.akb`），下载版则每种语言一个文件（`title_p_jp.akb`、`title_p_en.akb` 等）；找不到对应语言的文件时，运行时使用不带后缀的文件名。存档画面的图集是 `saveload_p.akb`（下载版为 `save_load_p_<语言>.akb`）。标题菜单的格子使用下载版可执行文件中为日文列出的那一套。
