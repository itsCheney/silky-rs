# engine-2021

English | [简体中文](engine-2021.zh-CN.md)

The engine of `fuyukuru.exe` 1.0.1.0 (ふゆから、くるる。), linked 2026-03-18 with Visual Studio 2022, SHA-256 `eeaf1f25cfcc8105c0d0720a46266815c2bb3ee28696cc1374f863f8cdfdb707`. The game came out in 2021; this copy was linked again later.

This is the base profile: the engine classes in `crates/silky-runtime/src/host.rs` were first written against this build, and games not known yet get it. [engine.md](../engine.md) lists what the runtime does for each class.
